AutoVideoUpload Privacy Policy

Last updated: 2026-11-07 · Home

Who uses this app

AutoVideoUpload is a personal tool used only by its owner to manage the owner's own YouTube channel. It is not offered to the public.

Google user data accessed

  • youtube.upload — to upload videos that the tool rendered to the owner's channel.
  • youtube.readonly — to confirm which channel is authorized (so it never uploads to the wrong account) and to read public statistics (views, likes, comments) of the videos it uploaded.

How data is used and stored

  • The OAuth token is stored only on the owner's own computer. It is never sent anywhere except to Google's APIs.
  • Video statistics are stored in a local database on the owner's computer to decide which video formats work better.
  • No Google user data is sold, shared with third parties, or used for advertising.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time from Google Account permissions. Deleting the local token file removes all stored credentials.

Contact

Use the support email shown on the Google consent screen of this app.

プライバシーポリシー（日本語）

AutoVideoUpload は、所有者が自身のYouTubeチャンネルを運用するためだけに使用する個人用ツールです。一般には提供していません。

  • youtube.upload：ツールが生成した動画を所有者のチャンネルへアップロードするために使用します。
  • youtube.readonly：認証されたチャンネルが正しいか確認し（誤ったアカウントへの投稿防止）、アップロードした動画の公開統計（再生数・高評価・コメント数）を読み取るために使用します。
  • OAuth トークンは所有者のPC内にのみ保存され、GoogleのAPI以外へ送信されません。
  • 動画の統計は、どの形式の動画が効果的かを判断するため、所有者のPC内のデータベースにのみ保存します。
  • Googleのユーザーデータを販売・第三者提供・広告目的で利用することはありません。Google API から取得した情報の利用は、Limited Use 要件を含む Google API Services User Data Policy に従います。
  • アクセス権は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。ローカルのトークンファイルを削除すると、保存された認証情報はすべて消去されます。
  • お問い合わせは、本アプリの Google 同意画面に表示されるサポートメールまでお願いします。
